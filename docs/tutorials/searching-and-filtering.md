# Searching and Filtering

!!! note "Coming soon"
    This tutorial is under development. It will cover the full range of discovery tools available in crategraph.

## What you'll learn

- Fuzzy text search with `search()` for finding entities by name or description
- Structural filtering with `select()` for narrowing by type, time range, and connectivity
- Property filtering with `where()` for exact matches and numeric ranges
- Pattern matching with `pattern()` for finding specific relationship structures
- Chaining methods together for progressive refinement
- Using `expand()` to discover related entities beyond your current filter
