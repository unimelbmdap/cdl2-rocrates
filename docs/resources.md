# RO-Crate Resources

This page provides links to sources of RO-Crates (Research Object Crates) that are informing the development of these tools.

## Collections

### University of Melbourne - OHRM Upload Project

**Link**: [https://figshare.unimelb.edu.au/projects/OHRM_Upload_Project/230466](https://figshare.unimelb.edu.au/projects/OHRM_Upload_Project/230466)

The Online Heritage Resource Manager (OHRM) Upload Project contains datasets from the University of Melbourne's former eScholarship Research Centre, transformed into RO-Crate format as part of the Describo Collections Integration Project (funded by the ARDC). This project rescues and preserves valuable heritage datasets by converting OHRM databases into modern RO-Crate packages, making them accessible for future researchers. Each dataset includes comprehensive metadata in `ro-crate-metadata.json`, digital content in an `objects` folder (where applicable), and original Microsoft Access/PostgreSQL datafiles in an `ohrm` folder.

### Language Data Commons of Australia (LDaCA)

**Link**: [https://data.ldaca.edu.au/search](https://data.ldaca.edu.au/search)

The Language Data Commons of Australia provides access to thousands of collections, objects, files and notebooks of nationally significant language data. The portal contains diverse collections including Aboriginal and Torres Strait Islander languages, regional languages of the Pacific, Australian English and migrant languages, sign languages of Australia and its region. The entire LDaCA data portal is built on RO-Crates, using them as the storage method for the repository with controlled access.
